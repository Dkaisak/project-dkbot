# El bot funciona solo con la stdlib (ctypes incluido).
#
# --- App de escritorio (opcional) ---
#   pywebview  -> ventana nativa (usa WebView2 en Windows)
#   pystray    -> icono de bandeja del sistema
#   Pillow     -> icono (y tambien lo usa pystray)
#   pip install pywebview pystray Pillow
#
# Sin estas dependencias, `main.py app` cae al modo navegador (`main.py gui`).
#
# --- Linux (opcional, input X11) ---
#   python-xlib   ->  pip install python-xlib      (preferido)
#   o xdotool     ->  apt install xdotool
# Memoria en Linux usa /proc/<pid>/mem + ptrace (stdlib).
#
# --- Capa de decision con LLM (opcional) ---
#   langgraph langchain-openai   ->  pip install langgraph langchain-openai
#   Requiere la seccion `llm` (config.json) habilitada y una API key de
#   OpenCode Zen/Go en la variable de entorno OPENCODE_API_KEY.
#   Sin estas dependencias (o sin key) el bot funciona igual: la capa LLM
#   queda inactiva y se usa la politica de prioridades clasica.
